# Submission Checklist

## Product

- [ ] Public web URL loads without authentication
- [ ] Wallet connects and switches to BOT Chain Mainnet
- [ ] USDT approval, deposit, agent execution, and withdrawal succeed
- [ ] Transaction states and failures are understandable
- [ ] Explorer links resolve to the demonstrated transactions

## Engineering

- [ ] Public GitHub repository contains original history
- [ ] README setup works from a fresh clone
- [ ] Contract tests and application checks pass
- [ ] Deployed addresses and transaction hashes are documented
- [ ] No private keys, API secrets, placeholder links, or false claims remain

## Presentation

- [ ] Short problem, solution, AI role, and safety explanation
- [ ] Architecture diagram showing the authority boundary
- [ ] Demo video covers the complete business loop
- [ ] AI contribution is visible in the executed decision
- [ ] RWA is described as roadmap unless actually integrated

## Evidence log

Create a dated submission record containing the public URL, repository URL,
contract addresses, key explorer links, demo wallet, test command output, video
URL, and the exact submitted description.
